# Wait What

Adapted from Matt Pocock's [wait-what](https://github.com/mattpocock/skills/tree/main/skills/productivity/wait-what)
skill (MIT).

Your last message did not land. Re-pitch it:

- Start with a little context: what you were doing, and why it matters to the
  user's goal.
- Write in ASD-STE100 Simplified Technical English: short sentences, one idea
  per sentence, active voice, common words.
- Use the project's own terms. If the repo has a `GLOSSARY.md`, use it (follow
  `GLOSSARY-MAP.md` to the right one if there is more than one). Otherwise use
  the words the user has used in this conversation.
- Define any term the user has not seen yet, or replace it with a plain one.

Do not repeat the original message with small edits, apologize, or add new
work. Re-pitch only, then stop.
